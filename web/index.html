Eine Game Jam ist ein Zusammentreffen von Personen, um gemeinsam innerhalb einer kurzen Zeitspanne ein Spiel zu entwickeln. Dabei arbeiten Personen mit verschiedenen Kenntnissen interdisziplinär zusammen.
